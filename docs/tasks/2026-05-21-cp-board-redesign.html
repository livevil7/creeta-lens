03 / 06 · GOAL

목표 — 검증 가능한 결과물

단순 viewer가 아니라, 세 폴더의 문서를 한 화면에서 보고 md→html 전환까지 거는 단일 보드.

board-builder 재작성 — docs/{tasks,history,rules}의 md+html 직접 스캔 → 단일 board_creeta-lens.html 생성, tasks/history/rules 카운트 출력.
3폴더 통합 뷰 — file://로 열면 세 폴더의 md·html 문서가 모두 카드로 표시.
뷰어 분기 — html 클릭 → 슬라이드 데크 iframe / md-only 클릭 → 원본 + "전환" 버튼.
전환 버튼 — 클릭 시 /cp html <경로> 클립보드 복사 + 토스트 (Claude 재생성 요청).
CONVERT 모드 — /cp html <md> → 같은 폴더에 슬라이드 데크 html 생성 + 보드 재빌드.
재배포 검증 — 소스 수정 후 /lens-upgrade → 캐시 버전 일치 (캐시는 휘발, 소스가 SoT).

1

스캐너 재작성

board-builder.js: 3폴더 md+html 스캔, basename 페어링, repo명 도출, md inline(escape·40KB 캡·stale 유지), schema v3.
2

board 템플릿

3폴더 그룹 + 뷰어 pane. md는 escape+<pre>+textContent(XSS 차단). 전환버튼 클립보드 + 실패 모달.

SKILL.md

신규 /cp html <file> CONVERT 모드. 보드 기본 생성(opt-in 해제), board_<repo>.html, reports/ 폐기. builder idempotent.
4

CSS 경로 정합

html이 폴더에 흩어지므로 _shared.css 위치/상대경로 단일화. conversion-spec 동기.
5

config 연동

6

마이그레이션 + 버전

reports/ 비파괴 보존(하드삭제 금지). 3.5.0 → 3.6.0, CHANGELOG 마이그레이션 노트.
7

검증 + 재배포

성공기준 6개 수기 검증 → 커밋 → /lens-upgrade → claude plugin list 버전 확인.
05 / 06 · RISKS

사전 리스크

Opus(세션 컨텍스트) + Codex(독립 분석). data-loss급 Blocker 없음 — 모두 설계 제약·신규 step으로 흡수.

Codex · 치명

md inline XSS

md에 script·iframe·onerror 섞이면 file:// 보드에서도 임의 JS 실행. → md는 escape+textContent만, innerHTML/파싱 금지.

Codex · UX

전환 버튼 silent 실패

file://·비보안·권한·제스처로 클립보드 차단 시 복사 실패인데 변환된 줄 오해. → 성공/실패 토스트 + 실패 모달(수동 복사).

Codex · 호환

reports/ 폐기 충격

기존 reports 링크/automation 404·카드 누락. → 하드 삭제 금지, 비파괴 보존 + 선택적 마이그레이션 안내.

Opus · 원칙

md = SoT 유지

board에 md inline해도 board는 파생 스냅샷. 진실은 디스크. stale 해시 감지 보존 — inline이 디스크와 어긋나면 stale 표시.

Codex · 성능

대용량 md inline

큰 md를 통째 inline하면 board 비대. → 40KB 초과 truncate + "원본 열기" 링크.

Opus · 단순성

마크다운 라이브러리 불필요

"보기 좋은" 렌더는 Claude 생성 html의 몫. board의 md뷰는 escape 텍스트로 충분 — XSS 차단과 단순성 동시 달성.

06 / 06 · RESUME

재개 포인트

다음 세션 진입 시 여기부터. 데이터 계약(builder 출력 schema)이 모든 후속의 전제.

step 1(board-builder 데이터 모델)을 먼저 확정해야 template·SKILL이 그 위에 올라간다. 구현 타깃은 creeta-lens 소스 — 캐시 수정은 휘발.

  1. step 1 — board-builder.js 재작성

    3폴더 md+html 스캔 → schema v3. node lib/board-builder.js로 board_creeta-lens.html 생성 확인.

  2. step 2 — board.template.html 재작성

    XSS-safe md뷰(escape+pre) + 전환버튼. <script> 포함 픽스처로 미실행 확인.
정적 file://는 폴더를 못 읽고 Claude를 못 부른다 — 그래서 board는 굽고, 전환은 클립보드로 명령을 넘긴다.
