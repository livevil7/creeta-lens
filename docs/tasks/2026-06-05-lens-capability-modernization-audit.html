03 / 06 · GOAL

목표 — 무엇이 가능해지는가

사람 언어로 "끝나면 가능해지는 것". 기술 증거는 검증표로 격리.

한 명령 · 4차원 양면 감사 — /cr 한 번으로 ① 노후도(유효/얇게/무의미) ② 업그레이드 벡터 ③ 편의 개선 ④ 대화-마이닝 신기능 제안을 분류 리포트로.
근거 + 핸드오프 — 분류마다 라이브 probe(로컬 CLI)+공식 체인지로그 근거가 붙고, 확신 높은 업그레이드는 /cp task로 자동 생성.
Pass 1 실증 완료 — 이 4차원 감사를 멀티에이전트로 1회 실행: 0 OBSOLETE / 2 KEEP / 9 THIN + 14 우선조치 + 신기능 /cx (/ch는 일반화 불가로 드롭).
레포 한정 알림 — 감사가 오래되거나 기능 구성이 바뀌면 creeta-lens 레포에서 세션 시작 시에만 한 줄 알림. 타 프로젝트엔 안 뜸.
false-obsolete 안전 — 아직 필요한 기능을 실수로 "제거"로 찍지 않는다. 죽음 판정은 사람이 결정할 제안으로만 남고 코드를 자동 삭제하지 않는다.
