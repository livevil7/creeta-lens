# 승인 한 번이면 끝까지 — /cc 무정지 실행

문제: 계획을 승인해도 `/cc` 가 실행 중간에 "Plan B 로 갈까요?"·"이어서 할까요?" 를 묻는다. 승인 한 번이 어디까지 허락인지 스킬에 없다.
해야 할 것: 승인 뒤에는 마지막 검증까지 묻지 않고 진행하고, 멈추는 경우를 세 가지로 못 박고, Claude Code 에서는 훅으로 강제한다.
대표 결정: 없음 (2026-09-14 "진행해")

## 🎯 목표

- 대표가 계획을 한 번 승인하면 `/cc` 가 마지막 검증과 최종 보고까지 중간 질문 없이 끝낸다.
- 멈추는 경우는 세 가지뿐이다 — 되돌리기 어려운 행동, 돈·외부 발송, 승인 범위를 넘어야 하는 경우. 배포·DB 변경·발송 같은 위험 행동은 계획에 있어도 멈춘다(대표가 "묻지 말고 하라" 고 한 것만 예외).
- Claude Code 에서는 실행 중 세 가지가 아닌 질문창이 뜨지 않는다.

Done: 승인된 계획을 `/cc` 로 실행하는 동안 정지 3종이 아닌 질문창을 부르면 훅이 거부하고, 스킬 어디에도 "승인 뒤 확인을 묻는" 절차가 남아 있지 않다.

## ❓ 왜

대표가 직접 한 말이 근거다 — *"1,2,3 다 해. 싹다 해 멀 자꾸 하나하나 할라그래 싹 다 하라고."*(2026-09-04) · *"이제 그만 물어보고 구현하지?"*(2026-08-14). v3.39 가 `/cp` → `/cc` 사이의 두 번째 승인은 없앴지만, 실행 도중 멈추는 곳은 남아 있다. 안 하면 대표는 계속 "싹 다 하고 보고해" 를 타이핑하고, 자리를 비운 사이 작업이 질문 하나에 멈춰 있다.
