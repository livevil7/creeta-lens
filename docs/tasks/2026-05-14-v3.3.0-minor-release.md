## 기술적 접근
- **왜 minor (3.3.0)**: API 변경(source 구조)이 추가됐고 새 helper(`formatPluginSource`)가 export됨. 그러나 `formatPluginSource(string)`이 fallback이라 기존 코드는 안 깨짐 → semver minor가 정확.
- **왜 patch가 아닌가**: KNOWN_PLUGINS의 source 데이터 구조 자체가 바뀜. plugin-registry 모듈을 import하는 외부 코드(session-start.js 같은)가 새 형식 알아야 함. 단순 버그 픽스를 넘어선 변경.
- **bump-version.sh 신뢰**: 정규식(`v[0-9]+\.[0-9]+\.[0-9]+`)이 v3.2.2 → v3.3.0을 자동 매칭. 이전 v3.1.0 → v3.2.x에서 일어난 stale hardcoded 문제가 재발하지 않음 (이미 v3.2.2 commit `fa17c45`에서 검증됨).
- **CHANGELOG 채우기**: bump-version.sh가 빈 template을 prepend. 사용자 또는 release manager가 Added/Changed/Removed 항목을 한국어로 작성.
