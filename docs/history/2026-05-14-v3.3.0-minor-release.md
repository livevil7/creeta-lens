# Lens v3.3.0 — minor release 완료

**완료일**: 2026-05-14

## 요약

`lib/plugin-registry.js`의 `KNOWN_PLUGINS` source 필드를 string에서 typed object(`{type, repo}`)로 변경하고, 신규 `formatPluginSource()` helper를 export하는 minor release. 핵심 원인은 Claude Code plugin loader가 string source(`'ccplugins/awesome-claude-code-plugins'`)를 `/` 기준으로 split해 owner를 가짜 marketplace ID로 잘못 해석하던 패턴. 구조적 차단으로 해결.

## 주요 결정 사항

- **semver minor 선택**: `formatPluginSource()`가 string fallback을 포함해 backward compat 유지 → breaking 아님. patch가 아닌 minor가 정확.
- **bump-version.sh 정규식 신뢰**: v3.2.2의 `fa17c45` commit에서 도입한 `v[0-9]+\.[0-9]+\.[0-9]+` 매칭이 첫 실전 작동. 10/10 파일 자동 sync 성공.
- **master + tag 분리 push**: 옛 tag(v1.9.0, v2.0.0) conflict 회피를 위해 `git push origin master` 와 `git push origin v3.3.0` 분리 실행.
- **CHANGELOG 직접 채움**: bump-version.sh가 prepend한 빈 template에 한국어로 Added/Changed/Fixed/Note 작성.
