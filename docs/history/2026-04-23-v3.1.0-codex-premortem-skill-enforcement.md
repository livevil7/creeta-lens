# Lens v3.1.0 — Codex Pre-mortem + Skill Enforcement — 완료

**완료일**: 2026-04-23
**Release**: v3.1.0

## 요약

`/cp` PLAN 모드에 Phase 2.5 Pre-mortem 단계를 추가해 Claude Opus + Codex GPT-5.2 병렬로 계획 문서의 리스크를 사전 분석하도록 했고, `/c` 와 `/cc` 의 Worker 프롬프트를 강화해 할당된 스킬을 반드시 호출하도록 강제하면서 Supervisor가 그 호출 여부를 감사하도록 만들었다.

## 주요 결정 사항

- **두 모델 병렬 pre-mortem**: 같은 모델로 자기 검증 시 동일 편향 공유 문제. Opus(세션 컨텍스트 기반) + Codex(독립 코드 분석)의 교차 검증으로 블라인드 스팟 해소.
- **Codex 미설치 환경 fallback**: `command -v codex` 또는 VSCode 확장 경로 감지. 부재 시 "Codex 미설치 — Opus 단독" 명시 표기. 설치 강제 안 함.
- **Supervisor 조건부 opus 승격**: Worker 할당에 `opus` 포함 시 Supervisor 도 자동 opus 승격. "주니어가 시니어 코드 리뷰" 역전 구조 해소. 단순 태스크는 sonnet 유지로 비용 절약.
- **Skill Enforcement는 강제 명령문으로**: 기존 "할당된 Skill (있는 경우)" 참고 문구를 "필수 실행 스킬 (SKIP 금지)" 명령문으로 교체. 첫 액션 = `Skill invoke` 강제. 완료 보고 첫 줄 `Skill invoked: /{skill_name}` 필수.
- **Supervisor 감사 조항**: Worker 보고에서 `Skill invoked:` 라인 누락 시 해당 서브태스크 점수 0점 + 재작업 지시. `general` 명시 태스크는 감사 제외.
- **Phase 2/2.5 분리 Write**: Phase 2.5 실패해도 Phase 2 의 계획 문서는 이미 저장됨. 원자성 보장.
