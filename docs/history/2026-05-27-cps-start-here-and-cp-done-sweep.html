03 / 06 · HOW IT WORKS

/cps 5단계 절차

인터랙티브 스킬이라 Claude의 Glob/Read가 곧 ground-truth evidence.

1·2

인벤토리 → 조립

docs/**/*.md(START_HERE 자신 제외)+README/CLAUDE.md Read → 4섹션 조립. 근거 부족은 (Not documented yet).
3·4

diff 게이트 → write

기존 파일 있으면 diff+승인 후에만 갱신(비파괴). docs/ 없으면 생성.
5

조건부 포인터

CLAUDE.md에 START_HERE 포인터 없을 때만 1줄 주입. 있으면 무변경, CLAUDE.md 신규 생성 안 함.
