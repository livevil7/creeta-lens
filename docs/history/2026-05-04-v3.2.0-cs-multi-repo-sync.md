# Lens v3.2.0 — `/cs` Multi-Repo Sync — 완료

**완료일**: 2026-05-04
**Release**: v3.2.0

## 요약

워크스페이스 하위 모든 git repo 를 일괄 동기화하는 신규 skill `/cs` 를 추가하고, SessionStart 마다 자동으로 incoming 변경을 pull 하는 hook 도 함께 등록했다. push 는 안전성 우선 정책으로 자동 실행하지 않고 사용자가 명시적으로 `/cs` 또는 `/cs push` 를 호출할 때만 발동한다. 사용자가 여러 기기 (Windows desktop, Mac mini, 노트북) 에서 같은 워크스페이스를 다루는 환경에서, 어느 기기에서든 lens 만 활성화하면 동일한 sync 동작을 받을 수 있게 됐다.

## 주요 결정 사항

- **Plugin 자체 등록 vs livevil-setting 의존**: lens self-contained 로 결정. `scripts/git-sync-all.sh` 를 lens 안에 두고, livevil-setting 의 같은 파일과 분리. 노트북에 livevil-setting clone 안 되어 있어도 lens 만 있으면 작동.
- **자동 pull + 명시적 push (방식 C)**: SessionStart 에서 `git pull --ff-only` 자동 실행. Stop 에서 자동 push 는 하지 않음. push 가 자동으로 발동되면 미완성 코드도 올라갈 위험 있어 사용자가 의도적으로 호출하도록.
- **opt-out 메커니즘**: `LENS_SYNC_AUTO_PULL=0` 환경변수로 SessionStart auto-pull 끔. plugin level 토글이 아니라 환경변수 — 더 가볍고 사용자별 cusotomization 가능.
- **Cross-platform Bash 자동 감지**: Windows Git for Windows (`C:/Program Files/Git/bin/bash.exe`), msys64, WSL fallback. macOS/Linux `/bin/bash`. 사용자가 어느 노트북에서든 추가 설정 없이 작동.
- **Fail-soft 처리**: 한 repo 실패가 나머지 진행을 막지 않음. Diverged repo 는 손대지 않고 `manual resolve required` 로만 보고. Auto-merge 시도 안 함 (안전).
- **Auto-commit message 정형화**: `chore: auto-sync YYYY-MM-DD` 단일 라인. 매번 같은 패턴이라 git log 에서 식별 쉬움. Author 강제 (`livevil7 <livevil7@gmail.com>`).
- **이전 PC 전용 setup 폐기**: 이전엔 `~/.claude/settings.json` 에 SessionStart/Stop bash hook 직접 박고 `~/.claude/commands/sync-all.md` 슬래시 커맨드 파일 두는 방식이었음. lens v3.2.0 통합 후 양쪽 다 제거 → marketplace 통한 단일 source of truth.

## 변경 파일

- `skills/cs/SKILL.md` (신규) — `/cs` 명령 정의: `pull` / `push` / `sync` 3 모드, Bash resolution, 사용 패턴, fail-soft 정책 명시
- `scripts/git-sync-all.sh` (신규) — POSIX shell 스크립트. workspace 자동 감지, fetch → ff-pull → auto-commit → push 4 단계 파이프라인. 컬러 박스 리포트 출력
- `hooks/sync-pull.js` (신규) — Node 기반 SessionStart hook. cross-platform Bash 자동 resolve, 90초 timeout, fail-soft (오류 발생해도 세션 시작 막지 않음)
- `hooks/hooks.json` — SessionStart 배열에 sync-pull entry 추가 (once: true). 기존 session-start.js 와 별개 등록
- `.claude-plugin/plugin.json` — version 3.1.0 → 3.2.0, description "Skill navigator + multi-repo git sync" 로 확장, keywords `git-sync` `multi-repo` `auto-pull` 추가
- `.claude-plugin/marketplace.json` — version + ref + description + tags 동기화
- `CHANGELOG.md` — v3.2.0 entry
