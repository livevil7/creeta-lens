02 / 04 · HOW IT WORKS

board-builder 파이프라인

md = SoT. HTML 슬라이드와 board는 항상 md에서 파생.

1

Scan

docs/{tasks,history} 스캔 → md + html 쌍 감지, lens:* 메타 추출.
2

Build

카드 나열 board.html 생성. 카드 클릭 → 오른쪽 iframe panel 즉시 표시(페이지 전환 없음).
3

Stale 감지

lens:source-hash 불일치 카드는 stale 표시 + 재생성 권고. _shared.css 최초 1회 배포.
03 / 04 · KEY DECISIONS

왜 이렇게 설계했나

01

md = SoT, HTML = 파생

상태/요약을 HTML에 원본 저장 금지. 항상 md에서 파생 — 단일 진실원.

02

opt-in → always-on

처음엔 reportFormat opt-in(기본 md)으로 md-only 프로젝트 무영향. v3.6.0 재설계에서 always-on 승격.

03

자산 자동 배포

_shared.css를 cp 실행 시 최초 1회 배포(있으면 skip → 사용자 커스텀 보존).
