03 / 07 · PROBLEM

왜 했나

기존 보드는 reports/만 인덱싱하는 opt-in. 사용자는 3폴더 통합 + md→html 전환을 원함.

Before (v3.5.0)

docs/reports/*.html만 스캔. reportFormat: html opt-in. rules 미포함. md→html 수단 없음.

After (v3.6.0)

docs/{tasks,history,rules} 직접 스캔 → 단일 board_<repo>.html 기본 생성. md-only엔 "convert to html" 버튼.

04 / 07 · HOW IT WORKS

동작

정적 file:// 3대 제약(폴더 못 읽음·Claude 못 부름·파일 못 씀)을 설계 전제로.

1

build

board-builder.js가 3폴더 md+html 스캔, md 본문 inline(escape·40KB 캡·stale 해시) → board_<repo>.html.
2

view

카드 클릭 → slide-over. html=iframe 슬라이드 데크 / md-only=원본(textContent, XSS-safe) + 전환버튼.
3

convert

전환버튼 → /cp html docs/<경로> 클립보드 복사 → 붙여넣기 → Claude가 슬라이드 html 생성 + 보드 재빌드.
05 / 07 · DECISIONS

주요 결정

전환 = Claude 재생성 요청 — 정적 버튼만으론 슬라이드 데크 품질 불가. 클립보드로 명령 전달.
전면 재설계 + 비파괴 — reports/ 폐지하되 기존 reports/·board.html 삭제 안 함.
XSS = escape + textContent만 — innerHTML/마크다운 파싱 금지 → 라이브러리 불필요(단순성).
라이트 보드 클론 — 다크 초안 반려 후 livevil-contents 기준 보드를 베이스로. Rules는 보라 액센트 참조 구분.
