05 / 07 · DECISIONS

주요 결정

사용자 반려 1회가 스펙의 핵심 규칙을 만들었다.

단계 층 노드 = 화면(스크린) 단위

초판 dogfood 가 단계를 스크립트/작업 단위로 묶어 사용자 반려 → "이용자가 실제로 보는 화면/뷰만 단계 노드" 로 강제, 화면 인벤토리는 라우트/템플릿에서 도출. v3.23.1 로 즉시 패치.

Additive-only 이식 원칙

하네스가 이미 강제하는 규칙은 재복붙 금지 — 예외는 워커 디스패치 프롬프트·Lens 특화 지점·3중 반복뿐. 스킬당 ~40줄 상한, 삭제 0줄 (fable-prompts 의 Lossless Transformation 교훈).

비공식 출처는 재서술 + 기준 버전 명시

추출본 원문 복붙 금지(정확성·라이선스 동시 회피), 기준 Claude Code 2.1.172 명시, 버전업 시 /crv 재대조 채널. 충돌 3건(모델 할당·승인 게이트·5분 보고)은 심사 후 전부 Lens 설계 유지.

디자인 SoT = 05-dark-developer 토큰 임베드

livevil-setting design.md 토큰(색·헤어라인 보더·radius·모션)을 템플릿에 임베드해 타 머신에서도 동작. 폰트만 한국어 커버리지로 Pretendard 유지(편차 명기).
